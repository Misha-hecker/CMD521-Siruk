Доробити практичну яку почали на парі.

1. Можливість вказати dst адресу (-d )
2. Можливість вказати таймаут (-t)
3. Має бути статистика: кількість підправлених пакетів, кількість тих які првернулисть, втратились. 
Найшвидший час RTT, Найдовший RTT, Середній час RTT.
4. Підміна src адреси (-s )
5. Надсилати TCP SYN пакети від випадкових src IP або з підміною src IP
